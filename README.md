# The Day You Lived

Type a date — any date. See what the world was like that day.

**Live:** [the-day-you-lived.vercel.app](https://the-day-you-lived.vercel.app)

## What's on the page

The page opens as a cover. Pick a date and it transforms into a dated broadsheet with four live dispatches:

- A historical event from that calendar day
- A notable person born on it
- The weather in your city on that exact date (records since 1940)
- An observance or holiday recorded for the day

All four pulled live from free public APIs — Wikipedia (events, births, holidays), Open-Meteo (historical weather), and ipapi.co (your location). No API keys. No fakes.
